#Car Price Exploratory Data Analysis (EDA)

#Overview
This repository contains an end-to-end Exploratory Data Analysis (EDA) project using Python. The analysis focuses on identifying key automobile attributes (such as horsepower, fuel efficiency, and vehicle type) that impact market pricing.

#Key Highlights& Insights
-Preprocessing: Handled missing values using median/mean imputation techniques.
-Correlation Analysis:Mapped relationships between horsepower engine metrics, and market price.
-Visualizations:Created clear scatter plots and correlation heatmaps to highlight trends.

#Tools&Libraries Used
Language:Python
Libraries:Pandas,NumPy,Matplotlib,Seaborn

#How to Run
1.Open the code directly in **Google Colab** or Jupyter Notebook.
2.Load the dataset from the provided public URL.
3.Execute cells sequentially to reproduce figures and statistical summary tables.
